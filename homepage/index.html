One space, many modes.A conversation can become a media feed, a multiplayer quiz or a scheduled video call without leaving the system.

More than a chat window.

Rantlist starts with real-time channels and direct conversations, then layers visual media, browser-based calling, a native calendar and multiplayer interaction into the same environment.

01 / CHAT

Channels & private spaces

Persistent WebSocket chat, direct conversations, grouped speech bubbles and live presence.

02 / MEDIA

Stories-style media

Images, GIFs, audio and video can move from the conversation into an immersive vertical viewer.

03 / CALLS

Audio & video

Browser-based real-time calls live beside the conversation instead of in a separate service.

04 / CALENDAR

Schedule inside Rantlist

Plan calls, invite Rantlist users or external guests, manage reminders and join from the same system.

05 / PLAY

Multiplayer built in

Quizzes, drawing games, chess and checkers turn a channel into a shared interactive space.

06 / APPEARANCE

Make it yours

Interface scaling, saved themes and expressive message styling let the same room feel very different.

Think Discord or Slack meeting Stories and lightweight multiplayer — but as one web-native space.

Rantlist is not built around an algorithmic infinite feed. It is closer to a digital room: people arrive, talk, share something, play, call and leave.

The macOS, iOS and Android clients are native WebView shells for the same Rantlist service. The public client repository contains sanitized client-side code and desktop packaging — not the production server, database or private infrastructure.

Think Discord or Slack meeting Stories and lightweight multiplayer — but as one web-native space.

Rantlist is not built around an algorithmic infinite feed. It is closer to a digital room: people arrive, talk, share something, play, call and leave.

The macOS, iOS, Android, Windows and Linux clients wrap the same Rantlist service for their respective platforms. The public client repository contains sanitized client-side code and desktop packaging — not the production server, database or private infrastructure.

AI Slop Gallery joins Games

Rantlist 9.6.257 opens AI Slop Gallery directly from Games and lets the original Builder creator publish or revoke isolated public game links under /public/games/<uid>.

Long OpenAI answers without hidden truncation

Rantlist 9.6.256 adds explicit paid output ceilings up to 128k, a separate large OpenAI text-retention limit, and honest partial-download labeling when the provider itself stops at the selected cap.

Complete AI outputs, files and generated images

Rantlist 9.6.254 keeps long AI answers complete for Copy/download, lets /ai requests include bounded text/code/PDF/image attachments, and adds /ai image generation with normal protected media previews.

Paid AI requests are bounded and profiles restore cleanly

Rantlist 9.6.253 fixes OpenAI queue-status errors, enforces the selected paid output/reasoning cap with one paid OpenAI response per explicit command, adds Stop AI, and keeps Import JSON available on a fresh install while protecting nickname-to-UUID identity continuity.

Frontier AI requests can run for minutes

Rantlist 9.6.251 moves OpenAI BYOK text generation to the Responses background workflow, reports live provider progress, and clears stale running status on completion or failure. Privacy mode uses a bounded store:false polling window; an explicit Extended OpenAI jobs option enables the 15-minute stock wait for work expected to exceed 10 minutes.

Your OpenAI key now uses native secure storage

Rantlist 9.6.250 moves iOS/macOS BYOK keys to Apple Keychain and Android keys behind Android Keystore encryption. Browser keys are memory-only and are no longer persisted in localStorage.

Bring your own OpenAI API key

Rantlist 9.6.249 lets each user privately configure their own OpenAI key, choose GPT-6 Astra or GPT-5.6 models, and see per-call token and estimated USD usage without sharing one platform-wide credential.

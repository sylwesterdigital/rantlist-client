# Rantlist PICO Web App

Rantlist uses PICO's Web App/PWA distribution path. There is no PICO APK in this target.

Release source:
- App URL: https://rantlist.me/
- Manifest: https://rantlist.me/manifest.webmanifest

The release workflow validates the live app and manifest, snapshots the manifest and release metadata, creates a versioned GitHub release bundle, and exposes PICO on the Rantlist project homepage.

PICO Store submission is created as a **Web App** in the PICO Developer Platform and points at the hosted Rantlist URL.
